# SceneGrid

動画を 4×4 の 16 分割サムネイルで確認しながら、Windows の `System.Rating` に評価を書き込むアプリです。メイン窓はサムネイル確認と評価、動画本体の再生は独立した別ウィンドウで行います。

## 起動

Windows / Python 3.11 を使用します。初回は依存ライブラリをインストールしてください。

```powershell
python -m pip install -r requirements.txt
```

```powershell
python scenegrid.py
```

または `run_scenegrid.bat` をダブルクリックします。パッケージ版の起動先は `dist\SceneGrid.exe` に統一しています (Python は不要)。

## 主な操作

- `Ctrl+O`: フォルダを開く
- ドラッグ＆ドロップ: フォルダまたは動画ファイルを開く
- 中央の16分割表示・下の一覧・フォルダツリーの上にもドロップできます。動画ファイルなら、そのフォルダを開いて動画を選択します。
- `←` / `→`: 前後の動画へ移動
- 複数選択中の移動は、選択した動画の中だけで行います。
- `Ctrl+クリック` / `Shift+クリック`: 複数選択 / 範囲選択
- `Ctrl+D`: 表示中の動画だけを選択
- `Ctrl+G`: 独立したグリッド一覧を開く
- `1`〜`5`: 評価
- `0`: 評価を解除
- 右上の星: 評価。同じ星なら解除
- `Space`: 動画窓の再生 / 一時停止
- メインの場面サムネイルをクリック: その位置から動画窓で再生
- `Ctrl+ホイール`: 場面一覧を拡大・縮小 (グリッド一覧ではタイルサイズ)
- `Del`: 選択した動画をごみ箱へ
- グリッド一覧のダブルクリック / `Enter`: メインウィンドウを手前へ
- グリッド一覧の `Esc`: グリッドを閉じる

並び順は名前・更新日時の昇順 / 降順。評価の絞り込みは「以上 / 以下 / のみ」で、同じ星ボタンを押すと解除します。評価で絞り込んだときのコピー・移動は、一覧に表示中の全ファイルが対象です。

星による表示の絞り込みはメイン窓とグリッド一覧窓の両方で操作でき、相互に同期します。右クリックは動画を自動再生しません。「フォルダを表示」はメイン窓を手前に出し、左のツリーで対象フォルダを展開・選択します。

評価で絞り込み中にフォルダを開くと、評価の読み込みが終わるまで「読み込み中...」と表示します。拡大中のダブルクリックは再生せず全体表示へ戻ります。拡大中の単クリックはダブルクリックの判定後に再生します。

評価保存後に更新日時を戻せなかった場合は、成功扱いにせずステータスバーに理由を表示します。削除も、一部のファイルだけが削除された場合や途中で取り消した場合を件数付きで表示します。

Windows の評価を扱えない形式・書き込み権限のないファイルでは、保存できなかった理由をステータスバーに表示します。評価はファイル自身に保存し、独自の評価データベースは作りません。

対応拡張子は `.mp4`, `.mov`, `.m4v`, `.avi`, `.mkv`, `.wmv`, `.webm`, `.mpg`, `.mpeg` です。

設定は `%APPDATA%\SceneGrid\` に保存します。

実装と標準の対応は `UI-COMPLIANCE.md` に記載しています。

## ビルド・検証

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest test_scenegrid -v
.\build_scenegrid.bat
```

ビルドは常に `dist\SceneGrid.exe` を更新します。起動中で更新できない場合はエラーで停止し、別フォルダへの出力は行いません。`updated`、`standard`、`verified`、`fixes`、`release` は過去の作業用出力先です。
